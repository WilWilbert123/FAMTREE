# FAMTREE - Family Tree Application

A cross-platform family tree application that runs seamlessly on iOS, Android, and Web.

## Features

### Core Features
- **Family Tree Visualization**: Interactive 3D zoomable family tree with pinch/zoom/pan gestures
- **Dark/Light Mode**: Full theme support with automatic system theme detection
- **Authentication**: Simple email/password authentication (no email verification required)
- **Timeline**: View family events chronologically with date markers
- **Memories**: Photo gallery with upload support from camera/gallery
- **Members Management**: Complete CRUD operations for family members

### Technical Features
- Cross-platform (iOS, Android, Web)
- Real-time updates via WebSocket
- Image upload with Cloudinary
- Responsive design for all screen sizes
- Offline support with AsyncStorage
